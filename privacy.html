Privacy policy: Desi Publisher

Last updated: 21 November 2026

Desi Publisher is a private tool used only by the owner of the Khayali Pulao channel. It uploads and schedules the owner's own videos on the owner's own YouTube channel, Instagram account and Facebook Page. It is not offered to the public.

What it accesses

With the owner's permission, it uses the YouTube Data API and the Meta Graph API to upload videos, set titles, descriptions and publish times, and read basic channel and post details (channel name, video ids, view counts).

How data is stored

Login tokens are stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising. Nothing is collected from viewers.

Removing access

Access can be removed at any time from Google account permissions and Facebook settings (Business integrations).

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Contact

Through the Khayali Pulao YouTube channel.
